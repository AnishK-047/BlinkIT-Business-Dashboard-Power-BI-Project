## 📊 Blinkit Sales Insights Dashboard (Power BI)

This project presents an **interactive Power BI dashboard** built to analyze Blinkit grocery sales performance across items, outlets, tiers, and years.

### 🔍 Key Insights

* **Total Sales:** 1.20M
* **Avg Sales per Outlet:** 120.17K
* **Avg Sales per Kg:** 12.46
* **Average Item Rating:** 3.97 ⭐
* **Years of Operation:** 9

### 📈 Dashboard Highlights

* Sales vs Target analysis
* Sales by **Outlet Type**, **Tier**, and **Fat Content**
* Item-wise sales & visibility comparison
* Year-wise sales trends
* Item ratings analysis

### 🛠 Tools Used

* **Power BI**
* **DAX**
* **Data Modeling & Visualization**

### 🎯 Skills Demonstrated

* KPI design & storytelling
* Interactive filters & slicers
* Business insights from retail data
